## 🌟 What is ZimboMate V2?

ZimboMate V2 is a **complete digital companion** for Dungeon World tabletop RPG sessions, featuring:

### ✨ **Core Features**
- 🧙 **Complete Character Management** - Stats, HP, XP, bonds, alignment, debilities
- 🎲 **3D Physics Dice Rolling** - Beautiful 3D dice with particle effects
- 📜 **Dungeon World Moves** - All moves with intelligent suggestions
- 🎒 **Equipment Management** - Drag-and-drop inventory with load tracking
- 📝 **Session Tools** - Notes, timers, trackers, roll history
- 🗺️ **Campaign Management** - Sessions, NPCs, locations, journal
- 📁 **File Management** - Import, export, backup, file browser
- 👥 **Multiplayer Support** - Real-time dice sharing and sessions
- ⌨️ **Keyboard Shortcuts** - Power user efficiency features
- ♿ **Accessibility** - WCAG AA compliant for all players

### 🎮 **Built for Dungeon World**
- **2d6 Rolling System** - Proper Dungeon World mechanics
- **XP Sources** - Failed rolls, bonds, alignment actions
- **Debility System** - Automatic modifier application
- **Load Tracking** - Equipment encumbrance management
- **Move Integration** - Contextual suggestions and execution

## 🎯 Key Features Overview

### **Character Management** 🧙
Complete Dungeon World character sheets with automatic calculations, XP tracking, and all core mechanics including bonds, alignment XP, and debilities.

### **3D Dice System** 🎲
Physics-based 3D dice rolling with particle effects, spatial audio, and complete roll history. Supports all Dungeon World mechanics with automatic modifier application.

### **Session Tools** 📝
Professional session management with note-taking, custom trackers, timers, and comprehensive roll history. Perfect for both players and GMs.

### **Campaign Management** 🗺️
Long-term campaign tracking with session history, NPC management, location tracking, and campaign journal. Build persistent worlds.

### **File Management** 📁
Enterprise-grade data management with import/export, automated backups, file browser, and data validation. Never lose your campaign data.

### **Multiplayer Features** 👥
Real-time session sharing with synchronized dice rolls, session management, and collaborative play features.

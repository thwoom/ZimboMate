## 💡 Pro Tips

### Efficiency Mastery
1. **Learn Ctrl+K**: The command palette is the fastest way to do anything
2. **Tab Navigation**: Ctrl+1-6 for instant tab switching
3. **Context Switching**: Number keys (1-6) set stat modifiers in dice context
4. **Space Bar Power**: Universal "do the main action" key

### Workflow Optimization
1. **Character → Dice Flow**: Use number keys to set modifiers, then Space to roll
2. **Move → Roll Flow**: Select move, press Enter, automatically switches to dice
3. **Equipment → Character**: Changes automatically update character stats
4. **Session Flow**: Take notes while playing, review in roll history

### Accessibility Features
1. **Full Keyboard Navigation**: Every feature accessible via keyboard
2. **Focus Indicators**: Clear visual focus for keyboard users
3. **Screen Reader Support**: Proper ARIA labels throughout
4. **Reduced Motion**: Disable animations in Settings > Accessibility

### Customization Options
1. **Theme Shortcuts**: Quick theme switching for different environments
2. **Personal Workflow**: Customize shortcuts for your play style
3. **Accessibility Preferences**: Adjust for vision or motor needs
4. **Performance Tuning**: Monitor and optimize for your device

## 🎮 Context-Aware Shortcuts

### Smart Context Detection
ZimboMate automatically detects your current context and enables relevant shortcuts:

- **Dice Context**: Number keys set stat modifiers
- **Character Context**: Tab cycles through character sections  
- **Equipment Context**: Arrow keys navigate inventory
- **Session Context**: Quick note and timer creation
- **Campaign Context**: Fast NPC and location creation

### Multi-Modal Shortcuts
Some shortcuts work differently based on context:

- **Space**: Roll dice (dice context) or confirm action (other contexts)
- **Enter**: Use move (moves context) or confirm input (forms)
- **Tab**: Navigate sections (character) or cycle panels (campaign)
- **Arrow Keys**: Navigate lists or adjust values

## 🔧 Troubleshooting Shortcuts

### If Shortcuts Don't Work
1. **Check Focus**: Ensure the correct tab/element has focus
2. **Modal Dialogs**: Close any open dialogs with Esc
3. **Browser Conflicts**: Some browsers override certain shortcuts
4. **Refresh**: Ctrl+R to refresh if shortcuts stop responding

### Browser-Specific Notes
- **Chrome**: All shortcuts work as expected
- **Firefox**: Some Ctrl+Number shortcuts may conflict with tab switching
- **Safari**: Cmd key instead of Ctrl on Mac
- **Edge**: Full compatibility with all shortcuts

### Accessibility Considerations
- **Screen Readers**: All shortcuts announced properly
- **Motor Impairments**: Single-key alternatives available
- **Vision Impairments**: High contrast mode preserves shortcuts
- **Cognitive Load**: Command palette reduces need to memorize shortcuts

## 🎨 **Rose Pine Theme Implementation**

### **Theme Variants Available**
1. **Rose Pine** (Dark) - Warm, cozy default theme
2. **Rose Pine Dawn** (Light) - Soft, natural light theme  
3. **Rose Pine Moon** (Dark Alt) - Cooler alternative dark theme
4. **Auto** - Follows system preference
5. **High Contrast** - Accessibility-focused theme

### **Key Features**
- **Semantic Color System**: Game-specific color mappings (HP states, roll results, stats)
- **Accessibility Compliant**: WCAG AA contrast ratios, reduced motion support
- **Smooth Transitions**: Instant theme switching with elegant animations
- **Comprehensive Documentation**: Complete design system and implementation guides

### **Game-Specific Color Mappings**
- **HP States**: Full (Foam), Injured (Gold), Critical (Love), Dead (Muted)
- **Roll Results**: Success (Foam), Partial (Gold), Failure (Love)
- **Stats**: STR (Love), DEX (Gold), CON (Rose), INT (Iris), WIS (Foam), CHA (Pine)
- **Equipment**: Weapons (Love), Armor (Pine), Gear (Subtle), Magic (Iris)
